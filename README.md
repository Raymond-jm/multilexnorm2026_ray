# MultiLexNorm2026 ByT5 Experiments

This repository contains experiment code and notes for the MultiLexNorm2026 multilingual lexical normalization assignment.

The repository intentionally does **not** include downloaded datasets, generated JSONL samples, model checkpoints, or validation outputs. Those files can be regenerated locally from the official Hugging Face dataset snapshots.

## Project Layout

```text
configs/byt5/validation_languages.yaml   # Language-specific ByT5 experiment manifest
scripts/byt5/                            # ByT5 data building, training, evaluation, analysis
scripts/mfr/                             # MFR baseline/error analysis utilities
docs/                                   # Korean working notes and report draft material
experiments/experiment_log.md            # Experiment log with actual numeric results
report/                                 # ACL-style report scaffold
requirements-byt5.txt                    # Python dependencies for ByT5 experiments
```

Generated local directories:

```text
data/           # Hugging Face dataset snapshots
sample_data/    # Generated ByT5 token-level JSONL examples
outputs/        # Checkpoints, predictions, logs, comparison summaries
external/       # Optional external repositories
```

These generated directories are ignored by git.

## Environment Setup

Use Python 3.10+ with a virtual environment or conda environment.

```bash
cd /path/to/multilexnorm2026_ray

python3 -m venv .venv
source .venv/bin/activate

pip install -U pip
pip install -r requirements-byt5.txt
```

If your CUDA/PyTorch environment needs a specific wheel, install the matching `torch` version first, then install the remaining requirements.

## Download the Datasets

The experiments expect Hugging Face dataset snapshots in these paths:

```text
data/raw/multilexnorm2026-dev-pub
data/raw/multilexnorm2026-full-pub
```

Download them with:

```bash
mkdir -p data/raw

huggingface-cli download weerayut/multilexnorm2026-dev-pub \
  --repo-type dataset \
  --local-dir data/raw/multilexnorm2026-dev-pub

huggingface-cli download weerayut/multilexnorm2026-full-pub \
  --repo-type dataset \
  --local-dir data/raw/multilexnorm2026-full-pub
```

The current experiments use `multilexnorm2026-dev-pub` for train/validation experiments. In the checked data, `dev-pub` and `full-pub` have the same train/validation splits and differ in the test split.

## Build ByT5 Token-level Samples

The dataset already provides tokenized `raw` and `norm` lists. The sample builder keeps that tokenization exactly as provided and creates one seq2seq example per token:

```text
input:  left context <extra_id_0> raw_token <extra_id_1> right context
target: norm_token
```

Build samples for all languages:

```bash
python3 scripts/byt5/build_lang_byt5_examples.py \
  --data-dir data/raw/multilexnorm2026-dev-pub \
  --split train \
  --lang all \
  --output-dir sample_data/byt5/lang
```

Or build only one language:

```bash
python3 scripts/byt5/build_lang_byt5_examples.py \
  --data-dir data/raw/multilexnorm2026-dev-pub \
  --split train \
  --lang ko \
  --output-dir sample_data/byt5/lang
```

The output files look like:

```text
sample_data/byt5/lang/train_de_examples.jsonl
sample_data/byt5/lang/train_en_examples.jsonl
sample_data/byt5/lang/train_ko_examples.jsonl
```

## Run Language-specific Training and Validation

The main automation script trains language-specific ByT5 models and evaluates them on the public validation split. It also computes MFR scores on the same validation language and writes a comparison table.

Dry-run first:

```bash
python3 scripts/byt5/run_validation_language_experiments.py --dry-run
```

Run all languages that have validation data:

```bash
python3 scripts/byt5/run_validation_language_experiments.py
```

Run selected languages:

```bash
python3 scripts/byt5/run_validation_language_experiments.py --langs de,en,ko
```

The validation languages are:

```text
de en hr id iden ja ko nl sl sr th vi
```

Languages without public validation in the downloaded dataset are not included in this automatic validation loop.

## Checkpointing and Resume

The automation script saves intermediate checkpoints every 5000 steps by default:

```text
outputs/byt5/lang_<lang>_1epoch_bs4/checkpoint_step_5000
outputs/byt5/lang_<lang>_1epoch_bs4/checkpoint_step_10000
```

If training is interrupted with `Ctrl+C`, run the same command again. The script automatically resumes from the latest `checkpoint_step_N` unless the final checkpoint already exists.

Change the save interval:

```bash
python3 scripts/byt5/run_validation_language_experiments.py --save-every 2000
```

Ignore intermediate checkpoints and restart training:

```bash
python3 scripts/byt5/run_validation_language_experiments.py --force-train
```


## Manual Single-language Commands

The YAML file contains exact commands for each language:

```text
configs/byt5/validation_languages.yaml
```

Example for English:

```bash
python3 scripts/byt5/finetune_byt5.py \
  --examples sample_data/byt5/lang/train_en_examples.jsonl \
  --output-dir outputs/byt5/lang_en_1epoch_bs4 \
  --model-name google/byt5-small \
  --max-examples -1 \
  --max-steps 8804 \
  --batch-size 4 \
  --gradient-accumulation-steps 1 \
  --learning-rate 5e-5 \
  --warmup-steps 100 \
  --max-input-length 256 \
  --max-target-length 32 \
  --log-every 10 \
  --save-every 5000

python3 scripts/byt5/evaluate_checkpoint.py \
  --checkpoint outputs/byt5/lang_en_1epoch_bs4/checkpoint \
  --output-dir outputs/byt5/lang_en_1epoch_bs4/validation_eval_en \
  --lang en \
  --batch-size 64 \
  --limit-sentences -1
```

## Current Experiment Notes

Experiment notes and report drafting are written in Korean:

```text
experiments/experiment_log.md
docs/report_draft_ko.md
docs/progress.md
```

Important policy:

- Use only train split for training and dictionary construction.
- Use validation split for evaluation, model selection, threshold choice, and error analysis.
- Do not add validation-specific gold pairs directly to rules or dictionaries.
- Keep `data/`, `sample_data/`, and `outputs/` out of git.

## Reproducibility Checklist

1. Install dependencies from `requirements-byt5.txt`.
2. Download Hugging Face datasets into `data/raw/`.
3. Build language JSONL samples into `sample_data/byt5/lang/`.
4. Run `scripts/byt5/run_validation_language_experiments.py`.
5. Read the final comparison table at `outputs/byt5/validation_language_comparison/comparison_summary.md`.
